## 🧪 Laboratorio 09
### Actividad I - Autenticación con Firebase

Este proyecto implementa un sistema de autenticación de usuarios utilizando **Firebase Authentication** en Android. La aplicación permite el inicio de sesión con correo electrónico y contraseña, valida usuarios registrados y muestra mensajes de bienvenida personalizados.

---

## 🚀 Características

- Inicio de sesión mediante correo electrónico y contraseña.
- Integración con Firebase Authentication.
- Validación de usuarios registrados.
- Manejo de errores para credenciales inválidas.
- Registro automático de nuevos usuarios.
- Pantalla de bienvenida personalizada.

## 📋 Flujo de la Aplicación

1. El usuario ingresa su correo electrónico y contraseña.
2. Firebase verifica si las credenciales son válidas.
3. Si el usuario existe, se muestra una pantalla de bienvenida.
4. Si el correo no está registrado, se muestra un mensaje de validación.
5. Los nuevos usuarios pueden registrarse y acceder a la aplicación.
